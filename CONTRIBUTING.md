# Współpraca

Dziękujemy za zainteresowanie projektem! Oto jak możesz pomóc:

## Jak zgłosić błąd

1. Sprawdź, czy błąd nie został już zgłoszony w [Issues](../../issues)
2. Jeśli nie — utwórz nowe Issue używając szablonu "Bug report"
3. Opisz kroki do odtworzenia, oczekiwane i rzeczywiste zachowanie

## Jak zaproponować zmianę

1. Sforkuj repozytorium
2. Utwórz branch: `git checkout -b feature/moja-zmiana`
3. Wprowadź zmiany i napisz testy
4. Upewnij się, że testy przechodzą: `yarn test`
5. Utwórz Pull Request z opisem zmian

## Konwencje

- Commit messages w języku angielskim (conventional commits)
- Kod TypeScript, formatowany Prettierem
- Testy dla nowych funkcji
